## 🚀 Featured project — Tukhnanutha Dashboard

> A backend-first supervision platform: KPIs, risks, compliance, finance, alerts and operational steering across the entities of a group.

| Area | What I built |
|---|---|
| **Backend** | Python · FastAPI · SQLAlchemy · Pydantic · PostgreSQL · Alembic migrations |
| **Frontend** | Next.js · React · TypeScript with a BFF layer |
| **Security** | JWT in HttpOnly cookies · role-based access control (7 roles) · audit log |
| **Infrastructure** | Docker Compose · Caddy gateway with HTTPS/TLS · healthchecks · backup & restore |
| **Quality** | pytest · Playwright end-to-end tests · sprint-based delivery with GO / NO-GO reviews |
| **Data** | Strict separation of demo, simulated and real data · BI-ready KPI model · AI governance groundwork |
